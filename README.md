# Madeireira Itaipu

Site completo em HTML, CSS e JavaScript, com imagens locais.
Exportação da versão 9, publicada em 13/10/2026.

## Abrir no computador
Extraia o ZIP e abra index.html no navegador. Mantenha a pasta assets junto das páginas.
Não é necessário instalar dependências nem executar um build.

## Enviar para o GitHub
1. Crie um repositório em https://github.com/new.
2. Abra o repositório e escolha Add file > Upload files (ou uploading an existing file).
3. Envie todos os arquivos desta pasta, incluindo assets. Envie os arquivos extraídos, não o ZIP.
4. Confirme em Commit changes.

## Arquivos
- index.html: página inicial.
- produtos.html: produtos e marcas.
- servicos.html: serviços.
- sobre.html: história da empresa.
- contato.html: atendimento e endereços.
- style.css: cores, layout, responsividade e efeitos das logos.
- app.js: lista de contatos do WhatsApp, modal e menu móvel.
- assets/: imagens e logotipos usados no site.

## Editar
Edite diretamente os arquivos HTML, CSS e JavaScript. A lista de vendedores está em contacts, em app.js.
O campo MAIN_WHATSAPP pode ser preenchido com um número confirmado no formato 55DDDNUMERO para substituir a seleção de contatos por atendimento centralizado.
A cor principal #097835 está em --green, no arquivo style.css.

## Observações
Esta é uma cópia independente. Alterações feitas no GitHub não se sincronizam automaticamente com o site publicado no ChatGPT.
Este pacote contém os arquivos editáveis do site, sem credenciais, histórico Git ou configurações internas de hospedagem.
